#  Joint modeling of choices and response times in value-based decision making

This study discusses whether reaction time (RT) provides information beyond choices in a probability dis
counting task. Data from 49 participants completing two 200-trial runs were modelled using hyperbolic prob
ability discounting and a logistic choice rule, with subjective value differences driving both choice and RT.
Three RT mappings were compared: An absolute conflict model, a squared conflict model allowing a nonlinear
conflict effect, and an exponential model assuming a bounded value-to-RT relationship. Models were evalu
ated using parameter recovery, test-retest reliability, and out-of-sample prediction. Recovery of β was strong
(r = 0.94-0.95), whereas recovery of b was weak (r = 0.43-0.49). RT modelling substantially improved aggre
gate recovery of h for the absolute and squared models, but not the exponential model. Test-retest reliability of
β remained high, while h showed some improved stability with RT modelling. The exponential model provided
the best held-out RT prediction in both reward and loss conditions. However, no RT model improved held-out
choice prediction relative to the choice-only baseline. Consequently, the exponential model provided the best fit for RT prediction, while the additional information gained from RTs in modelling choices was limited and parameter-specific.
